Travis Claypool Reindeer Games Messaging Program

By texting START to the program number, you agree to receive score tallies and related game messages from Travis Claypool. Message frequency varies. Message and data rates may apply.

Program Description

Travis Claypool Reindeer Games is a score updates messaging program run by Travis Claypool for a yearly holiday game. Participants who opt in receive score tallies and related game messages, such as round announcements, reminders, and final results, during the game season.

How to Opt In

Text START to the program number. You will receive a confirmation message once you are enrolled. Opting in is voluntary and is not a condition of any purchase. Sign-up details are posted at travisclaypool.com/reindeer-games.

Message Frequency

Message frequency varies. Messages are sent during the game season.

Cost

Travis Claypool does not charge for these messages. Message and data rates may apply, depending on your mobile plan.

Help

Help: Reply HELP for help. You can also reach Travis Claypool through the contact form at travisclaypool.com.

Opt-Out

Opt-out: Reply STOP to cancel. You will receive one message confirming that you have been unsubscribed, and no further messages will be sent. Reply START to rejoin.
